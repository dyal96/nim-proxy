Help Guide

Learn how to use NIM Control Center

What is NIM Proxy?

This proxy bridges the gap between powerful local AI coding agents (like Claude Code, Continue, Cline) and NVIDIA NIM's diverse model ecosystem. Because many AI agents are hardcoded to only understand the "Anthropic" or "OpenAI" API format, this proxy translates those formats automatically into NVIDIA's format.

You also get this comprehensive dashboard to track usage, compare model speeds, and chat directly with models locally!

Dashboard & Analytics

Every API call made through this proxy (whether from the Chat page or your IDE) is logged in a local SQLite database (`usage.db`). The Dashboard visualizes this data, showing you how many tokens you're burning through and what your average latency is. You can purge this data anytime from the Settings page.

Live Benchmarking

Not sure which model to use? The Benchmark tab streams real tokens and calculates the actual TPS (Tokens Per Second) and TTFT (Time To First Token) for any model available on NVIDIA NIM. Use this to find the fastest model for your hardware or internet connection.

IDE Integration

To use the active NIM model in your editor, go to the IDE Configs tab. It generates exact copy-paste configurations for tools like Claude Code, Continue, Cline, and Crush.

Pro tip: When you change the model in the Settings tab, all your IDE extensions connected to the proxy will automatically start using the new model. No need to update their configs!

DeepSeek Reasoning Support

The Chat UI natively parses and formats <think> tags outputted by reasoning models like DeepSeek-R1. It renders them as beautiful collapsible dropdowns so they don't clutter your main conversation.
